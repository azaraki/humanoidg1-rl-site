# HumanoidG1-RL · Landing Site

Apple-style landing page for [HumanoidG1-RL](https://github.com/azaraki/HumanoidG1-RL) — the Unitree G1 reinforcement-learning locomotion stack.

## Stack
- Single `index.html` — no build step, no framework
- Google Fonts (Inter, Instrument Serif, JetBrains Mono)
- Deployed on Vercel

## Local preview
Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy
```bash
vercel --prod
```
